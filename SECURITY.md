# Security Policy

ION Launch is a real-money crypto application and follows a conservative safety model.

## Non-Negotiables

- We do not deploy custom token-launch contracts.
- We do not custody user funds.
- We do not sign transactions server-side.
- We do not store private keys, seed phrases, or wallet secrets.
- We do not hide transaction destinations from users.

## Reporting Issues

If you find a security issue, avoid public disclosure until it is reviewed. Share reproduction steps, affected routes, wallet/network context, and transaction hashes if relevant.
